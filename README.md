# Gabriela Davidson's Personal Website
### ENVS 193DS | Spring 2026

## General Information

**What is this repo for?**
This repository contains the source code for my personal Quarto website, 
created as a final project for ENVS 193DS at UC Santa Barbara. The website 
serves as a digital portfolio showcasing my academic journey, work experience, 
projects, and interests in environmental education.

**Who is contributing?**
This repo is maintained by Gabriela Davidson (GitHub: gdavidson533), 
a 3rd year Environmental Studies and Education Minor student at UCSB.

---

## Data and File Information

**Files and folders:**

- `index.qmd` — Landing page with photo, bio, and contact links
- `about.qmd` — About Me page with background, academic journey, and travel photos
- `projects.qmd` — Projects listing page in blog format
- `fun.qmd` — My Santa Barbara page with favorite food and outdoor spots
- `resume.qmd` — Resume page with embedded PDF
- `_quarto.yml` — Website configuration file (navbar, theme, CSS)
- `styles.css` — Custom CSS for colors and fonts
- `posts/` — Folder containing all blog post files
  - `grizzly-bear/` — Grizzly bear reintroduction lesson plan post with interactive map
  - `coding-project/` — ENVS 193DS midterm statistical analysis post
  - `job-experience/` — Environmental education work experience post
  - `rag-doll/` — Rag Doll Surf business post
- `photos/` — Travel and personal photos used throughout the site
- `docs/` — Rendered HTML output served by GitHub Pages

**What does the code do?**
The `.qmd` files use Quarto markdown to render HTML pages that make up 
the website. The `grizzly-bear` post includes an interactive leaflet map 
showing the historical range of California grizzly bears. The `_quarto.yml` 
file controls the site structure, navigation, and theme. Custom colors and 
fonts are applied through `styles.css`.
